# TamTree company website

Responsive one-page website for TamTree LLC. Content is based on the current company website: web and mobile app development, full-stack expertise, SAP and PeopleSoft training, technology staffing, learner programs, company approach, and India/USA office contacts.

## Original-site content cross-check

The current page includes the original site’s innovation/transformation message; About description and India/USA presence; all four featured services and their key details; five “Why Choose Us” points; the technologies list; live classes, interactive sessions, full-stack development topics, manual testing, communication training and career-support wording; both office addresses and phone numbers; the website link; and the Name, Email, Message and Submit contact-form fields.

The contact form is only a front-end preview and does not deliver messages yet. Connect it to a real form/email service before launch. Confirm the Austin street spelling (“Blcones Drive”) and current office/course details with TamTree.

## View

Open `index.html` in a browser. The website uses plain HTML, CSS, and JavaScript; no installation or build process is required.

## Project structure

- `css/styles.css` contains the site styles.
- `js/script.js` contains the navigation and contact-form interactions.
- `assets/images/` contains the logo and optimized page images.
- `assets/illustrations/` contains reusable SVG illustrations.
- `assets/source/` contains the original artwork files retained for reference.
